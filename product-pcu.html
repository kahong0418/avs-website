Introduction

PCU Solution Overview

AVS LED Price Change Unit (PCU) is a complete petrol station (forecourt) price display solution designed for clear visibility, outdoor reliability, and easy on-site maintenance. It is commonly installed on pylons and signboards to display fuel prices consistently in day and night conditions.

AVS PCU is available in multiple models and sizes, allowing sign makers and site owners to match the right digit height, colour, and configuration for each station.

Why AVS PCU

Benefits

Outdoor Protection & Sealing

Sealed construction with protective coating and IP-rated connectors to withstand rain, heat, humidity, and continuous operation.

Aluminium Housing (Anti-Corrosion)

Aluminium casing helps resist corrosion and supports long service life in outdoor environments.

Auto Brightness (Light Sensor Per Module)

Each LED module includes a light sensor to auto-adjust brightness based on real ambient conditions. This maintains readability and prevents over-brightness — even when weather changes suddenly (e.g., heavy rain making the sky dark).

Monolith Backlight Auto Control (No External Timer Needed)

The PCU system can control the monolith backlight to turn ON/OFF automatically based on day/night conditions. This saves the cost and complexity of external timers and ensures more accurate operation when lighting conditions change unexpectedly.

Modular Design for Faster Service

Modular design supports quicker replacement and easier servicing on site, reducing downtime and maintenance disruption.

Integration-Ready (Remote Price Update)

Integration-ready design supports remote price update workflows through common controller/POS environments (subject to project requirements).

Component Quality

Quality-controlled components with branded LED options available (e.g., Osram/Cree depending on model/project).

PCU System Overview

System Overview

What the PCU System Does

The AVS LED Price Change Unit (PCU) is a complete price display system for petrol station (forecourt) applications.

New prices are entered using one of three input methods: remote control, counter terminal, or POS/forecourt system. The price data is sent to the PCU controller, which then drives the LED price display modules installed on the pylon or monolith.

The system also supports additional automated functions:

  1. Automatic brightness control via light sensors on each module
  2. Automatic monolith backlight ON/OFF control via PCU controller (project-based configuration)

Core Components

PCU Controller (Main Control Unit)

  • Receives price data from the chosen input method
  • Drives all connected LED price display modules
  • Sends/receives brightness control signal
  • Can control monolith backlight ON/OFF (depending on project wiring)
Full controller & terminal specs →

LED Price Display Modules (Digit Modules)

  • Mounted on the pylon/monolith signage
  • Available in different digit heights and colours
  • Aluminium casing to minimise corrosion
  • Sealed for outdoor use
  • Each module includes a light sensor

Cables & IP-Rated Connectors

  • Outdoor-grade cabling between controller and modules
  • IP-rated connectors to handle rain and humidity
  • Plug-and-unplug style connection for easier installation and service

Three Input Methods

Remote Control

  • Handheld remote used to update prices directly
  • Suitable for simple or smaller sites where POS integration is not required

Counter Terminal

  • Small terminal placed at the cashier or control room
  • Staff can key in new prices from inside the shop
  • Can be configured to link with 3rd-party POS / forecourt systems (project-based)

POS / Forecourt System

  • Prices are sent from the station’s POS or forecourt controller
  • PCU receives price commands via the agreed project interface
  • Suitable for branded networks or stations with central price control

Additional Control Features

Automatic Brightness Control

  • Each digit module has its own light sensor
  • The system adjusts brightness based on real ambient conditions
  • Keeps digits readable and avoids over-brightness, even when the sky suddenly turns dark (e.g. heavy rain)

Automatic Monolith Backlight Control

  • PCU controller can turn monolith backlight ON/OFF automatically
  • Reacts to actual light conditions, not just a fixed timer
  • Helps save energy and reduces the need for external timers and manual adjustment

Engineering Data

PCU Specification

Display Type

Standard 7-Segment PCU

Standard 7-segment digits for fuel price display — widely used for most pylons and monoliths. Suitable for typical layouts such as 8.888, 8.8.8.8, and 5-digit configurations (project-based).

Multi-Segment / Custom Format PCU

Multi-segment formats are used for special layouts, custom dot positions, mixed digit sizes, or brand-specific requirements. This is suitable when the signage design needs a non-standard layout or special spacing.

Digit Height Range & Common Sizes

We support a range of digit heights depending on project requirement. Common sizes include:

175 mm / 200 mm / 250 mm / 300 mm / 336 mm (and other sizes project-based).

Digit Layout

Common price display layouts include:

  • 8.888 (4 digits with decimal)
  • 8.8.8.8 (4 digits with full dots)
  • 5-digit formats (project-based)

Colour Options

Available colours (depending on model/project): Red / White / Green / Dual-colour (Red + White).

White digits on a Vivo station installation.

Supply Type — Complete Unit vs Module-Only

We can supply PCU as a Complete Unit (with back plate/casing) or as Module-Only for retrofit and custom sign structures. The final supply type depends on the site design and installer preference.

Price Update Method

Three Ways to Update Fuel Prices

AVS PCU supports three ways to update fuel prices, allowing the system to match different station operations — from simple standalone sites to projects requiring POS/forecourt integration.

Method A — Remote Control (Standalone)

A handheld remote control allows staff to update prices quickly without using a POS system. This option is suitable for sites that want a simple and fast price change method.

Typical use cases:

  • Independent stations
  • Quick retrofit / simple setups
  • Sites without POS integration requirement
Wireless remote full specs →

Method B — Counter Terminal (Shop-Side Input)

The counter terminal is placed at the cashier or control room, allowing staff to update prices from inside the station. It provides a structured daily operation workflow and can be configured to interface with 3rd-party systems depending on project requirements.

Typical use cases:

  • Stations that prefer shop-side control
  • Step-by-step upgrades (terminal first, integration later)
Price Sign Terminal full specs →

Method C — POS / Forecourt System Integration (Project-Based)

For stations that require centralized control, AVS PCU can be configured to receive price updates from a POS / forecourt controller environment. This enables consistent pricing workflows across sites and supports remote price update operations.

Controller / protocol compatibility: AVS PCU is compatible with common IFSF-based forecourt controllers, and we continue to expand compatibility to support new controller platforms.

Compatibility depends on the site interface and must be confirmed during project evaluation.

Typical use cases:

  • Branded networks and oil companies, including Tela
  • Stations with standardized forecourt systems
  • Projects requiring automation and integration
